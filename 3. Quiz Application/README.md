# Quiz Application

An interactive Python command-line quiz application with score calculation, explanations, and detailed final performance breakdown.

## Core Features
- **Display Multiple-Choice Questions (MCQs)**: Cleanly formatted question and 4-choice options.
- **Score Calculation**: Computes points and percentage accuracy.
- **Immediate & Final Feedback**: Shows correct vs. incorrect choice with clear technical explanations.
- **Performance Evaluation**: Provides grade assessment and summary breakdown.
- **Replay Support**: Retake or exit smoothly.

## Concepts Demonstrated
- **Conditional Statements**: Answer evaluation (`if/elif/else`), grading logic, input sanitization.
- **Loops**: Iterating through questions (`for`) and retrying the quiz loop (`while`).
- **Functions**: Dedicated routines for displaying questions, getting input, scoring, and presenting results.
- **Dictionaries**: Question records containing options, correct answers, and explanations.

## How to Run
```bash
python quiz_app.py
```
